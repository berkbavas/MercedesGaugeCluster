# Mercedes Gauge Cluster

An open-source digital gauge cluster inspired by Mercedes-Benz, built with **C++** and **QML** using **Qt 5.15.2**.

## Getting Started

### Prerequisites

- Qt 5.15.2 (with Qt Creator recommended)
- C++ compiler (MSVC2019 or compatible)

### Build Instructions

1. Install **Qt 5.15.2** and Qt Creator.
2. Clone this repository.
3. Open `MercedesGaugeCluster.pro` in Qt Creator.
4. Configure the kit (e.g., Desktop Qt 5.15.2 MSVC2019 64bit).
5. Build and run the project.
